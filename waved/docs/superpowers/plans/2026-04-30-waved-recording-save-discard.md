# Waved Recording — Save / Send / Discard Confirmation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Insert a Save / Send / Discard confirmation screen between Stop and the recording's terminal disposition. Save = local-only. Send = local + queue upload through the existing retry path. Discard = hard-delete file dir + db row. Retire `[api].auto_upload`.

**Architecture:** Stop finalises the WAV synchronously and publishes a new `MeetingState.pending_decision` field carrying the data the UI needs (id, audio path, duration, size, endpoint snapshot). The UI auto-navigates to a new `ConfirmationScreen` while `pending_decision.is_some()` and back to Home when it clears. Three new `Command::{Save,Send,Discard}Recording(Uuid)` variants close the modal from the UI side. The existing `try_upload_with_retry` and wifi-reconnect-flush paths are reused for Send.

**Tech Stack:** Rust 2021, `hound` (already used for WAV), `sqlx` (sqlite), LVGL via `waved-ui::bindings`, `tokio::sync::{broadcast, watch, mpsc}`. No new dependencies.

**Reference spec:** `docs/superpowers/specs/2026-04-30-waved-recording-save-discard-design.md`

/// Delete a meeting and all its bookmarks atomically.
/// Used by `Command::DiscardRecording`. NotFound is a no-op (returns Ok).
pub async fn delete_meeting_cascade(
    pool: &SqlitePool,
    id: &Uuid,
) -> Result<(), sqlx::Error> {
    let mut tx = pool.begin().await?;
    sqlx::query("DELETE FROM bookmarks WHERE meeting_id = ?")
        .bind(id.to_string())
        .execute(&mut *tx)
        .await?;
    sqlx::query("DELETE FROM meetings WHERE id = ?")
        .bind(id.to_string())
        .execute(&mut *tx)
        .await?;
    tx.commit().await
}
```

//! ConfirmationScreen — Save / Send / Discard after recording stop.
//!
//! Layout (mockup A): title at top, duration + size, then path, then
//! endpoint, then a row of three 64×64 icon buttons at the bottom. See
//! `docs/superpowers/specs/2026-04-30-waved-recording-save-discard-design.md`
//! §7 for visual specifications.

use std::path::Path;

/// Format a recording's audio path for the confirmation screen.
///
/// Takes the absolute path (e.g. `/mnt/udisk/recordings/4f3a8e2c-…/audio.wav`),
/// truncates the immediate parent dir name to 8 chars + `…`, and keeps the
/// filename. Returns e.g. `4f3a8e2c…/audio.wav`.
///
/// If the path has no parent dir or the parent name is shorter than 8
/// chars, it's returned without truncation.
pub fn format_path(audio_path: &Path) -> String {
    let filename = audio_path
        .file_name()
        .map(|s| s.to_string_lossy().into_owned())
        .unwrap_or_default();
    let parent = audio_path
        .parent()
        .and_then(|p| p.file_name())
        .map(|s| s.to_string_lossy().into_owned())
        .unwrap_or_default();
    let parent_disp = if parent.chars().count() > 8 {
        let truncated: String = parent.chars().take(8).collect();
        format!("{truncated}…")
    } else {
        parent
    };
    if parent_disp.is_empty() {
        filename
    } else {
        format!("{parent_disp}/{filename}")
    }
}

/// Format an endpoint URL for display.
///
/// Strips `http://` or `https://`. If the remaining string is ≤ 28 chars,
/// returns it unchanged. Otherwise ellipsizes the *path* part, keeping the
/// host:port and the last path segment intact:
///
///   `https://example.com/api/v2/very/long/path/upload`
///   → `example.com/…/upload`
pub fn format_endpoint(url: &str) -> String {
    let without_scheme = url
        .strip_prefix("https://")
        .or_else(|| url.strip_prefix("http://"))
        .unwrap_or(url);
    if without_scheme.chars().count() <= 28 {
        return without_scheme.to_string();
    }
    let (host, path) = match without_scheme.split_once('/') {
        Some((h, p)) => (h, p),
        None => return without_scheme.to_string(),
    };
    let last_seg = path.rsplit('/').next().unwrap_or("");
    if last_seg.is_empty() {
        without_scheme.to_string()
    } else {
        format!("{host}/…/{last_seg}")
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use std::path::PathBuf;

    #[test]
    fn format_path_truncates_uuid_parent_dir() {
        let p = PathBuf::from("/mnt/udisk/recordings/4f3a8e2c-1234-5678-9abc-def012345678/audio.wav");
        assert_eq!(format_path(&p), "4f3a8e2c…/audio.wav");
    }

    #[test]
    fn format_path_keeps_short_parent_name_intact() {
        let p = PathBuf::from("/tmp/abc/audio.wav");
        assert_eq!(format_path(&p), "abc/audio.wav");
    }

    #[test]
    fn format_path_no_parent_returns_filename_only() {
        let p = PathBuf::from("audio.wav");
        assert_eq!(format_path(&p), "audio.wav");
    }

    #[test]
    fn format_endpoint_strips_https_scheme() {
        assert_eq!(
            format_endpoint("https://localhost:8080/meetings/upload"),
            "localhost:8080/meetings/upload"
        );
    }

    #[test]
    fn format_endpoint_strips_http_scheme() {
        assert_eq!(
            format_endpoint("http://localhost:8080/x"),
            "localhost:8080/x"
        );
    }

    #[test]
    fn format_endpoint_short_url_unchanged() {
        assert_eq!(format_endpoint("localhost:8080/x"), "localhost:8080/x");
    }

    #[test]
    fn format_endpoint_long_path_is_ellipsised_keeping_last_segment() {
        let r = format_endpoint("https://meetings.example.com/api/v2/very/long/path/upload");
        assert_eq!(r, "meetings.example.com/…/upload");
    }

    #[test]
    fn format_endpoint_no_scheme_no_path_unchanged() {
        assert_eq!(format_endpoint("localhost:8080"), "localhost:8080");
    }
}
```

#!/usr/bin/env bash
# Generate the three confirmation-screen icon PNGs (36×36, white on
# transparent) using ImageMagick `magick -draw`. Run once on a host
# machine; commit the resulting PNGs.
#
# Each icon is intentionally simple geometry — these are 36×36 mono
# bitmaps shown inside a 64×64 tinted bg button. Visual fidelity is fine
# at this resolution.
set -euo pipefail

OUT="$(cd "$(dirname "$0")/.." && pwd)/waved/crates/waved-ui/assets/icon/btn"
mkdir -p "$OUT"

W=36
H=36
COLOR="white"

# Save: floppy-disk shape — outer rounded square, top-left notch (label),
# bottom solid block (label area).
magick -size ${W}x${H} xc:none \
  -fill none -stroke "$COLOR" -strokewidth 2 \
  -draw "roundrectangle 4,4 32,32 3,3" \
  -fill "$COLOR" -stroke none \
  -draw "rectangle 10,4 26,12" \
  -draw "rectangle 8,22 28,30" \
  -fill none -stroke black -strokewidth 1 \
  -draw "line 22,6 22,10" \
  "$OUT/btn_save.png"

# Send: paper plane — triangle with a tail crease.
magick -size ${W}x${H} xc:none \
  -fill "$COLOR" -stroke none \
  -draw "polygon 4,32 32,4 18,18" \
  -fill none -stroke "$COLOR" -strokewidth 2 \
  -draw "line 32,4 18,18" \
  -draw "line 18,18 14,28" \
  "$OUT/btn_send.png"

# Discard: trash can — lid + body + two vertical lines.
magick -size ${W}x${H} xc:none \
  -fill none -stroke "$COLOR" -strokewidth 2 \
  -draw "rectangle 9,12 27,32" \
  -draw "line 6,10 30,10" \
  -draw "line 14,8 22,8" \
  -draw "line 14,8 14,10" \
  -draw "line 22,8 22,10" \
  -draw "line 14,16 14,28" \
  -draw "line 18,16 18,28" \
  -draw "line 22,16 22,28" \
  "$OUT/btn_discard.png"

echo "Wrote: $OUT/btn_{save,send,discard}.png"
ls -la "$OUT/btn_save.png" "$OUT/btn_send.png" "$OUT/btn_discard.png"

    tx: tokio::sync::broadcast::Sender<Command>,
    id: Uuid,
}

unsafe extern "C" fn save_btn_cb(e: *mut lv_event_t) {
    if lv_event_get_code(e) != lv_event_code_t_LV_EVENT_CLICKED {
        return;

    /// Verify the carried id matches the active pending_decision and

    fn validate_pending(&self, id: &Uuid) -> Option<PendingDecision> {

        match s.pending_decision {
            Some(d) if &d.id == id => Some(d),

/// Wait until `predicate(state)` returns true or the timeout elapses.
async fn wait_for<F: Fn(&MeetingState) -> bool>(
    rx: &mut watch::Receiver<MeetingState>,
    predicate: F,
) {
    let deadline = tokio::time::Instant::now() + Duration::from_secs(2);
    loop {
        if predicate(&rx.borrow()) {
            return;
        }
        if tokio::time::Instant::now() >= deadline {
            panic!("timed out waiting for predicate; state = {:?}", *rx.borrow());
        }
        let _ = tokio::time::timeout(Duration::from_millis(50), rx.changed()).await;
    }
}

async fn record_and_stop(h: &mut Harness) -> uuid::Uuid {
