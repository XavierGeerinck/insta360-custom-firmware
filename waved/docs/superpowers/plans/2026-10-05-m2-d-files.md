> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the two Files screens of the revision-2 redesign: the recordings list (D1) and the recording detail with a playback scrubber (D2). Show free space and low storage (D3, UI side). Everything is test-driven on the host against fixture snapshots, with goldens compared to `files.png` and `file-detail.png`.

- **Screens.** `screens_v2/files.rs` (`FilesScreen`) and `screens_v2/file_detail.rs` (`FileDetailScreen`) implement `kit::screen::Screen`. - **Data producers live in workstream C.** `FilesState` gets a producer in `waved-meeting` (new task C13, see "Cross-workstream dependencies"). `PlaybackState` comes from C8. D's screens are complete and tested without them, because they are driven by snapshot fixtures.

**Tech Stack:** Rust 2021, LVGL 9.2 via bindgen, the waved-ui kit (`Obj`, `event::on/on_click`, components, testkit goldens), `uuid`, tokio channels (`Dispatcher::test`).

## Review Focus

These five inputs aren't exercised by the happy-path goldens but are likely to hurt someone using the device. Each one has a test.

1. **A recording without a synced clock, or with an odd timestamp.** `started_at` may be `None` (no NTP at record time), carry nanoseconds and an offset (chrono's `to_rfc3339`), or be malformed. The title must read "Date unknown" or the right local day, and must never panic. *(Task 1: `when_label_survives_missing_and_odd_times`, `parse_rfc3339_accepts_chrono_output`)*
2. **A long or technical failure reason**, such as a server error string. It must stay on one line inside a 300 px box at y 218, end in "...", and never run under the bezel. *(Task 6: `a_long_failure_reason_stays_inside_the_note_box`)*
3. **The open recording disappears**, deleted through the confirmation or pruned by retention while its detail is open. The detail must go back exactly once and send no commands for the missing file. *(Task 6: `a_deleted_recording_leaves_the_detail_once`)*
4. **Dragging the knob past the top of the ring** (end ↔ start). The position must clamp at the end it came from, not jump across the file. *(Task 4: `dragging_past_the_top_clamps_instead_of_wrapping`)*
5. **Playback state that belongs to another recording, or that lags a seek.** The detail must show its own recording's duration and position, never another file's progress. After a seek it must hold the target until playback catches up or 1.5 s pass. *(Task 5: `another_recordings_playback_is_not_shown_here`, `a_seek_holds_its_target_until_playback_catches_up`)*

Also pinned:
- The list ordering (attention first, then the producer's newest-first order, capped at 50): `attention_first_then_newest_and_capped`.
- A rebuild while scrolled keeps the scroll position: `rebuilding_keeps_the_scroll_position`.

## Cross-workstream dependencies (not contract requests)

**Workstream C, proposed new item C13 "Publish FilesState" (`crates/waved-meeting/**`).** D3's producer belongs here. Please add it to C's plan and to `../TODO.md` under C. Specification:
- **`recordings`:** every meeting row except the active `Recording`, **newest first** by start (fall back to row creation order when `started_at` is `None`).
- **`RecordingStatus` mapping** from `model::MeetingStatus`:
  | MeetingStatus | RecordingStatus |
  |---|---|
  | `AwaitingDecision` | `AwaitingDecision` |
  | `LocalOnly` | `LocalOnly` |
  | `Finalized`, `Queued` | `Waiting` |
  | `Uploading` | `Uploading` |
  | `Uploaded` | `Uploaded` |
  | `RetryWait`, `ConfigurationError` | `Failed` |
  | `MissingArtifact`, `ArtifactError`, `LegacyUnsupported` | `Damaged` |
- **`last_error`:** for `Failed` and `Damaged`, a **lower-case plain phrase with no prefix**. The UI writes "Upload failed: {phrase}" or "File damaged: {phrase}". Suggested phrases:
  - timeout or connection refused: "server didn't answer"
  - DNS failure: "server not found"
  - TLS failure: "secure connection failed"
  - HTTP 4xx: "server refused it (4xx code)"
  - HTTP 5xx: "server error (5xx code)"
  - no endpoint: "no server set up"
  - missing WAV: "audio file missing"
  - unreadable WAV: "audio file unreadable"
  - legacy format: "old recording format"
  - Never raw error text or URLs.
- **`marks_ms`:** bookmark offsets from the start of the WAV in milliseconds, including any pre-roll, ascending.
- **`free_bytes`:** `statvfs(recordings_dir)`, `blocks_available × fragment_size`.
- **`low_space`:** `storage_blocked || free_mb < config.storage.minimum_free_mb`. This is the free-space half of `retention::needs_pruning`, the point from which new recordings depend on pruning.
- **When to publish:**
  - at start
  - after every status change: stop, decision, upload result, delete, prune, retry
  - every 60 s for free space
- **Tests** in `waved-meeting` (via `scripts/linux-test.sh`):
  - the mapping table
  - newest-first order
  - `low_space` at both sides of the threshold
  - `marks_ms` from bookmarks

**Workstream C, C7 and C8 behaviour the detail relies on:**
- `Command::RetryUpload(id)` moves a `LocalOnly` or failed recording to `Queued`. It already does (`db::reset_attempt_cycle`, `waved-meeting/src/lib.rs:565`); keep that for `LocalOnly` (Files' "Send").

  - **Calls.** During a call, set `playing = false` (C8 "pauses while a call is active").
  - **Playing another file.** `PlayRecording(other)` replaces the current playback.

/// is never cut off; older delivered recordings are pruned by retention.

/// Days since 1970-01-01 for a proleptic Gregorian date (H. Hinnant's algorithm).
fn days_from_civil(year: i64, month: i64, day: i64) -> i64 {
    let y = if month <= 2 { year - 1 } else { year };
    let era = y.div_euclid(400);
    let yoe = y - era * 400;
    let mp = (month + 9) % 12;
    let doy = (153 * mp + 2) / 5 + day - 1;
    let doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
    era * 146_097 + doe - 719_468
}

/// (year, month 1–12, day 1–31) for days since 1970-01-01.
fn civil_from_days(days: i64) -> (i64, usize, i64) {
    let z = days + 719_468;
    let era = z.div_euclid(146_097);
    let doe = z - era * 146_097;
    let yoe = (doe - doe / 1_460 + doe / 36_524 - doe / 146_096) / 365;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let day = doy - (153 * mp + 2) / 5 + 1;
    let month = if mp < 10 { mp + 3 } else { mp - 9 };
    let year = yoe + era * 400 + i64::from(month <= 2);
    (year, month as usize, day)
}

/// All-ASCII-digit field `range` of `text`, as a number.
fn digits(text: &str, range: std::ops::Range<usize>) -> Option<i64> {
    let part = text.get(range)?;
    if part.is_empty() || !part.bytes().all(|b| b.is_ascii_digit()) {
        return None;
    }
    part.parse().ok()
}

/// Seconds since the epoch for an RFC 3339 time: "2026-10-05T14:02:31Z",
/// "...T14:02:31.123456789+00:00" (chrono's `to_rfc3339`) or "...-01:00".
pub fn parse_rfc3339(text: &str) -> Option<i64> {
    let b = text.as_bytes();
    if b.len() < 20
        || b[4] != b'-'
        || b[7] != b'-'
        || !matches!(b[10], b'T' | b't' | b' ')
        || b[13] != b':'
        || b[16] != b':'
    {
        return None;
    }
    let (year, month, day) = (digits(text, 0..4)?, digits(text, 5..7)?, digits(text, 8..10)?);
    let (hour, minute, second) = (
        digits(text, 11..13)?,
        digits(text, 14..16)?,
        digits(text, 17..19)?,
    );
    if !(1..=12).contains(&month)
        || !(1..=31).contains(&day)
        || hour > 23
        || minute > 59
        || second > 60
    {
        return None;
    }
    let mut rest = text.get(19..)?;
    if let Some(fraction) = rest.strip_prefix('.') {
        let n = fraction.bytes().take_while(u8::is_ascii_digit).count();
        if n == 0 {
            return None;
        }
        rest = &fraction[n..];
    }
    let offset_s = match rest {
        "Z" | "z" => 0,
        _ => {
            let sign = match rest.as_bytes().first() {
                Some(b'+') => 1,
                Some(b'-') => -1,
                _ => return None,
            };
            if rest.len() != 6 || rest.as_bytes()[3] != b':' {
                return None;
            }
            let (h, m) = (digits(rest, 1..3)?, digits(rest, 4..6)?);
            if h > 23 || m > 59 {
                return None;
            }
            sign * (h * 3_600 + m * 60)
        }
    };
    Some(days_from_civil(year, month, day) * 86_400 + hour * 3_600 + minute * 60 + second - offset_s)
}

/// "Today, 14:02", "Yesterday, 16:45", "29 Sep, 09:15", or "31 Dec 2025" in
/// another year; "Date unknown" when the clock was not set at record time.
pub fn when_label(started_at: Option<&str>, now_unix_s: i64, offset_min: i32, clock_24h: bool) -> String {
    let Some(start) = started_at.and_then(parse_rfc3339) else {
        return "Date unknown".into();
    };
    let offset_s = i64::from(offset_min) * 60;
    let day = start.saturating_add(offset_s).div_euclid(86_400);
    let today = now_unix_s.saturating_add(offset_s).div_euclid(86_400);
    let time = format_clock(start, offset_min, clock_24h);
    match today.saturating_sub(day) {
        0 => format!("Today, {time}"),
        1 => format!("Yesterday, {time}"),
        _ => {
            let (year, month, d) = civil_from_days(day);
            let (this_year, _, _) = civil_from_days(today);
            let month = MONTHS[month - 1];
            if year == this_year {
                format!("{d} {month}, {time}")
            } else {
                format!("{d} {month} {year}")
            }
        }
    }
}

/// "45 s", "42 min", "1 h 05 min" (rounded to the nearest minute).
pub fn duration_label(secs: u32) -> String {
    if secs < 60 {
        return format!("{secs} s");
    }
    let minutes = (secs + 30) / 60;
    if minutes < 60 {
        format!("{minutes} min")
    } else {
        format!("{} h {:02} min", minutes / 60, minutes % 60)
    }
}

/// "3.2 GB free", "12 GB free", "850 MB free" (decimal units, rounded down so
/// the line never promises space that is not there).
pub fn free_space_label(bytes: u64) -> String {
    const MB: u64 = 1_000_000;
    const GB: u64 = 1_000_000_000;
    if bytes >= 10 * GB {
        format!("{} GB free", bytes / GB)
    } else if bytes >= GB {
        format!("{}.{} GB free", bytes / GB, (bytes % GB) / (GB / 10))
    } else {
        format!("{} MB free", bytes / MB)
    }
}

/// The icon, its colour and the lower-case phrase for one upload state.

    match status {

        RecordingStatus::Damaged => (icons::ALERT, WARN, "file damaged"),
        RecordingStatus::Waiting if wifi_connected => (icons::CLOCK, TEXT_2, "waiting to send"),

        RecordingStatus::LocalOnly => (icons::DEVICE, TEXT_2, "kept on Wave"),

/// The phrase with its first letter capitalised ("Upload failed").
pub fn sentence(words: &str) -> String {
    let mut chars = words.chars();
    match chars.next() {
        Some(first) => first.to_uppercase().chain(chars).collect(),
        None => String::new(),
    }
}

/// Attention first, then the producer's newest-first order (a stable sort),
/// at most `MAX_ROWS`.
pub fn ordered(recordings: &[RecordingSummary]) -> Vec<&RecordingSummary> {
    let mut rows: Vec<&RecordingSummary> = recordings.iter().collect();
    rows.sort_by_key(|rec| !rec.status.needs_attention());
    rows.truncate(MAX_ROWS);
    rows
}

pub fn row_look(rec: &RecordingSummary, snap: &UiSnapshot) -> RowLook {
    let (icon, icon_color, words) = status_look(rec.status, snap.wifi.connected);
    RowLook {
        id: rec.id,
        icon,
        icon_color,
        title: when_label(
            rec.started_at.as_deref(),
            snap.now_unix_s,
            snap.utc_offset_min,
            snap.settings.clock_24h,
        ),
        line: format!("{}, {words}", duration_label(rec.duration_secs)),
    }
}

pub fn rows_for(snap: &UiSnapshot) -> Vec<RowLook> {
    ordered(&snap.files.recordings)
        .into_iter()
        .map(|rec| row_look(rec, snap))
        .collect()
}

    (after.low_space && !before.low_space)
        .then(|| Message::new(Severity::Warning, LOW_SPACE_MESSAGE))
}

const FADE_BOTTOM: i32 = 16;

/// What one card shows; the Files screen derives it from a `RecordingSummary`.
#[derive(Clone, Debug, PartialEq)]
pub struct RowLook {
    pub id: Uuid,
    pub icon: &'static str,
    pub icon_color: u32,
    pub title: String,
    pub line: String,
}

/// One card: state icon, title over the second line, chevron.
fn card(parent: Obj, look: &RowLook) -> Obj {
    let card = Obj::plain(parent)
        .size(CARD_W, CARD_H)
        .bg(SURFACE)
        .radius(CARD_RADIUS)
        .pressed_bg(RAISED)
        .clickable(true)
        .row_start(CARD_GAP, CARD_PAD_X);
    Obj::label(card, look.icon, Font::Icon20, look.icon_color);
    let text = Obj::plain(card).size(TEXT_W, SIZE_CONTENT).column(2);
    Obj::label(text, &look.title, Font::Body, TEXT).width(TEXT_W).one_line();
    Obj::label(text, &look.line, Font::Small, TEXT_2).width(TEXT_W).one_line();
    Obj::label(card, icons::RIGHT, Font::Icon20, TEXT_3);
    card
}

pub struct FileList {
    viewport: Obj,
    empty: Obj,
    cards: Vec<Obj>,
    rows: Option<Vec<RowLook>>,
    on_open: Rc<RefCell<dyn FnMut(Uuid)>>,
}

impl FileList {
    pub fn new(parent: Obj, on_open: impl FnMut(Uuid) + 'static) -> Self {
        let viewport = Obj::plain(parent)
            .rect(VIEW)
            .column_centered(CARD_PITCH - CARD_H);
        // SAFETY: live object.
        unsafe {
            lv_obj_add_flag(viewport.raw(), lv_obj_flag_t_LV_OBJ_FLAG_SCROLLABLE);
            lv_obj_set_scroll_dir(viewport.raw(), lv_dir_t_LV_DIR_VER);
            lv_obj_set_scrollbar_mode(viewport.raw(), lv_scrollbar_mode_t_LV_SCROLLBAR_MODE_OFF);
            lv_obj_set_style_pad_top(viewport.raw(), PAD_TOP, MAIN);
            lv_obj_set_style_pad_bottom(viewport.raw(), PAD_BOTTOM, MAIN);
        }
        fade(parent, Rect::new(0, VIEW.y, VIEW.w, FADE_TOP), true);
        fade(
            parent,
            Rect::new(0, VIEW.y + VIEW.h - FADE_BOTTOM, VIEW.w, FADE_BOTTOM),
            false,
        );
        let empty = Obj::plain(parent).rect(VIEW).hidden(true);
        Obj::label(empty, icons::FOLDER, Font::Icon44, TEXT_3)
            .centered_text(SCREEN_W)
            .pos(0, EMPTY_ICON_Y);
        Obj::label(empty, EMPTY_TEXT, Font::Small, TEXT_2)
            .wrapped_text(EMPTY_TEXT_W)
            .max_lines(3)
            .pos((SCREEN_W - EMPTY_TEXT_W) / 2, EMPTY_TEXT_Y);
        Self {
            viewport,
            empty,
            cards: Vec::new(),
            rows: None,
            on_open: Rc::new(RefCell::new(on_open)),
        }
    }

    /// Show `rows`. Unchanged rows keep their cards; a change rebuilds them
    /// and keeps the scroll position (clamped to the new content).
    pub fn set_rows(&mut self, rows: Vec<RowLook>) {
        if self.rows.as_ref() == Some(&rows) {
            return;
        }
        let scroll = self.scroll_y();
        for card in self.cards.drain(..) {
            card.delete();
        }
        for look in &rows {
            let card = card(self.viewport, look);
            let (open, id) = (self.on_open.clone(), look.id);
            on_click(card, move || (open.borrow_mut())(id));
            self.cards.push(card);
        }
        self.empty.hidden(!rows.is_empty());
        self.viewport.update_layout();
        self.scroll_to(scroll);
        self.rows = Some(rows);
    }

    pub fn card(&self, index: usize) -> Obj {
        self.cards[index]
    }

    pub fn len(&self) -> usize {
        self.cards.len()
    }

    pub fn is_empty(&self) -> bool {
        self.cards.is_empty()
    }

    /// Scroll so content offset `y` is at the top (LVGL bounds it).
    pub fn scroll_to(&self, y: i32) {
        self.viewport.update_layout();
        // SAFETY: live viewport.
        unsafe { lv_obj_scroll_to_y(self.viewport.raw(), y, lv_anim_enable_t_LV_ANIM_OFF) };
    }

    pub fn scroll_y(&self) -> i32 {
        // SAFETY: live viewport.
        unsafe { lv_obj_get_scroll_y(self.viewport.raw()) }
    }

    pub fn empty_state(&self) -> Obj {
        self.empty
    }
}

#[derive(Default)]
pub struct FilesScreen {
    status: Option<StatusArea>,
    free: Option<Obj>,
    list: Option<FileList>,
    /// The free line as last drawn (text, colour, shown), to skip restyling.
    free_shown: Option<(String, u32, bool)>,
}

impl Screen for FilesScreen {
    fn build(&mut self, root: Obj, ctx: &ScreenCtx, snap: &UiSnapshot) {
        self.status = Some(StatusArea::plain(root));
        Obj::label(root, "Files", Font::Title, TEXT)
            .centered_text(SCREEN_W)
            .pos(0, TITLE_Y);
        self.free = Some(
            Obj::label(root, "", Font::Micro, TEXT_3)
                .centered_text(SCREEN_W)
                .pos(0, SUBTITLE_Y),
        );
        let dispatch = ctx.dispatch.clone();
        self.list = Some(FileList::new(root, move |id| {
            dispatch.navigate(Route::FileDetail(id))
        }));
        back_button(root, &ctx.dispatch);
        self.update(snap);
    }

    fn update(&mut self, snap: &UiSnapshot) {
        if let Some(status) = self.status.as_mut() {
            status.update(snap);
        }
        if let Some(free) = self.free {
            // Before the first storage report free_bytes is 0 and low_space
            // false: show nothing rather than "0 MB free".
            let shown = snap.files.free_bytes > 0 || snap.files.low_space;
            let colour = if snap.files.low_space { WARN } else { TEXT_3 };
            let next = (free_space_label(snap.files.free_bytes), colour, shown);
            if self.free_shown.as_ref() != Some(&next) {
                free.hidden(!next.2).text_color(next.1).set_text(&next.0);
                self.free_shown = Some(next);
            }
        }
        if let Some(list) = self.list.as_mut() {
            list.set_rows(rows_for(snap));
        }
    }
}

//! The recording detail's playback scrubber (docs/mockups file-detail.png):
//! a progress ring of r 60 at (200, 140) with mark ticks on r 70, a knob to
//! drag, play/pause in the middle and the position under it. One round hit
//! area takes every touch; `press` / `drag` / `release` hold the gesture
//! logic so tests can drive it without an input device.

use crate::bindings::*;
use crate::kit::components::dial::{arc, arc_style, full_ring, INDICATOR, MAIN};
use crate::kit::event::on;
use crate::kit::fonts::Font;
use crate::kit::icons;
use crate::kit::obj::Obj;
use crate::kit::tokens::{lvgl_angle, polar, Rect, BG, LINE, LIVE, SCREEN_H, SCREEN_W, TEXT, TEXT_2};
use std::cell::RefCell;
use std::rc::Rc;

pub const CX: i32 = 200;
pub const CY: i32 = 140;
pub const R: i32 = 60;
const WIDTH: i32 = 4;
const TICK_R: i32 = 70;
const TICK_WIDTH: i32 = 6;
const TICK_SPAN: f32 = 3.0;
/// The knob: r 8 plus the mockup's 3 px black stroke, as a 20 px disc with a 3 px border.
const KNOB: i32 = 20;
const KNOB_BORDER: i32 = 3;
const PLAY_BOX: Rect = Rect::new(178, 102, 44, 44);
const TIME_Y: i32 = 152;
const TIME_W: i32 = 160;
/// Touches closer than this to the centre play or pause...
pub const CENTRE_R: f32 = 44.0;
/// ...and out to this radius they scrub (the ring, the ticks and some slop).
pub const HIT_R: i32 = 84;
/// A ring tap within this many degrees of a tick jumps to its mark: ±18° is
/// a 44 px arc on r 70, the minimum target size.
pub const MARK_SNAP_DEG: f32 = 18.0;
/// Movement beyond this turns a ring tap into a drag.
const DRAG_SLOP: f32 = 8.0;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Zone {
    Centre,
    Ring,
    Outside,
}

pub fn zone(x: i32, y: i32) -> Zone {
    let d = ((x - CX) as f32).hypot((y - CY) as f32);
    if d < CENTRE_R {
        Zone::Centre
    } else if d <= HIT_R as f32 {
        Zone::Ring
    } else {
        Zone::Outside
    }
}

/// Device degrees of (x, y) around the scrubber centre: 0 at the top, clockwise.
pub fn angle_at(x: i32, y: i32) -> f32 {
    ((x - CX) as f32)
        .atan2((CY - y) as f32)
        .to_degrees()
        .rem_euclid(360.0)
}

/// The next drag position for a finger at `angle_deg`, coming from `prev`
/// (0..1). A jump of more than half a turn means the finger crossed the top,
/// so the position stays at the end it came from instead of wrapping.
pub fn follow(prev: f32, angle_deg: f32) -> f32 {
    let next = angle_deg.rem_euclid(360.0) / 360.0;
    if (next - prev).abs() > 0.5 {
        if prev >= 0.5 {
            1.0
        } else {
            0.0
        }
    } else {
        next
    }
}

pub fn fraction(position_ms: u32, duration_ms: u32) -> f32 {
    if duration_ms == 0 {
        0.0
    } else {
        (f64::from(position_ms.min(duration_ms)) / f64::from(duration_ms)) as f32
    }
}

pub fn to_ms(fraction: f32, duration_ms: u32) -> u32 {
    (f64::from(fraction.clamp(0.0, 1.0)) * f64::from(duration_ms)).round() as u32
}

fn angular_gap(a: f32, b: f32) -> f32 {
    let d = (a - b).rem_euclid(360.0);
    d.min(360.0 - d)
}

/// The mark closest to `angle_deg`, if one is within `MARK_SNAP_DEG`.
pub fn nearest_mark(angle_deg: f32, marks_ms: &[u32], duration_ms: u32) -> Option<u32> {
    if duration_ms == 0 {
        return None;
    }
    marks_ms
        .iter()
        .map(|&mark| (mark, angular_gap(angle_deg, fraction(mark, duration_ms) * 360.0)))
        .filter(|(_, gap)| *gap <= MARK_SNAP_DEG)
        .min_by(|a, b| a.1.total_cmp(&b.1))
        .map(|(mark, _)| mark)
}

/// "14:52", or "1:05:00" from an hour on.
pub fn clock(ms: u32) -> String {
    let s = ms / 1_000;
    if s >= 3_600 {
        format!("{}:{:02}:{:02}", s / 3_600, s / 60 % 60, s % 60)
    } else {
        format!("{}:{:02}", s / 60, s % 60)
    }
}

pub fn time_text(position_ms: u32, duration_ms: u32) -> String {
    format!("{} / {}", clock(position_ms), clock(duration_ms))
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ScrubEvent {
    /// The middle was tapped.
    TogglePlay,
    /// The ring was tapped or dragged and let go here (ms from the start).
    Seek(u32),
}

#[derive(Clone, Copy, Debug, PartialEq)]
enum Gesture {
    Idle,
    Centre,
    Scrub { x: i32, y: i32, at: f32, moved: bool },
}

#[derive(Clone, Debug, Default, PartialEq)]
struct Shown {
    position_ms: u32,
    duration_ms: u32,
    marks_ms: Vec<u32>,
    playing: bool,
    playable: bool,
}

struct Inner {
    layer: Obj,
    ring: Obj,
    knob: Obj,
    icon: Obj,
    time: Obj,
    hit: Obj,
    ticks: Vec<Obj>,
    shown: Option<Shown>,
    gesture: Gesture,
}

#[derive(Clone)]
pub struct Scrubber {
    inner: Rc<RefCell<Inner>>,
    on_event: Rc<RefCell<dyn FnMut(ScrubEvent)>>,
}

/// Where the active pointer is, during one of its events; `None` in the
/// headless tests, which have no input device.
fn point() -> Option<(i32, i32)> {
    // SAFETY: the active input device is valid during its event; null otherwise.
    unsafe {
        let indev = lv_indev_active();
        if indev.is_null() {
            return None;
        }
        let mut p = lv_point_t::default();
        lv_indev_get_point(indev, &mut p);
        Some((p.x, p.y))
    }
}

impl Scrubber {
    pub fn new(parent: Obj, on_event: impl FnMut(ScrubEvent) + 'static) -> Self {
        let ring = arc(parent, CX, CY, R, WIDTH);
        full_ring(ring);
        arc_style(ring, MAIN, LINE, 255, WIDTH);
        arc_style(ring, INDICATOR, LIVE, 255, WIDTH);
        // Ticks go in a full-screen layer under the knob, created now so
        // rebuilding them never changes the stacking order.
        let layer = Obj::plain(parent).rect(Rect::new(0, 0, SCREEN_W, SCREEN_H));
        let knob = Obj::plain(parent)
            .size(KNOB, KNOB)
            .round()
            .bg(TEXT)
            .border(KNOB_BORDER, BG)
            .hidden(true);
        let play = Obj::plain(parent).rect(PLAY_BOX);
        let icon = Obj::label(play, icons::PLAY, Font::Icon44, TEXT)
            .center()
            .hidden(true);
        let time = Obj::label(parent, "", Font::Num13, TEXT_2)
            .centered_text(TIME_W)
            .pos(CX - TIME_W / 2, TIME_Y)
            .hidden(true);
        let hit = Obj::plain(parent)
            .pos(CX - HIT_R, CY - HIT_R)
            .size(2 * HIT_R, 2 * HIT_R)
            .round()
            .clickable(true);
        let scrubber = Self {
            inner: Rc::new(RefCell::new(Inner {
                layer,
                ring,
                knob,
                icon,
                time,
                hit,
                ticks: Vec::new(),
                shown: None,
                gesture: Gesture::Idle,
            })),
            on_event: Rc::new(RefCell::new(on_event)),
        };
        let s = scrubber.clone();
        on(hit, lv_event_code_t_LV_EVENT_PRESSED, move |_| {
            if let Some((x, y)) = point() {
                s.press(x, y);
            }
        });
        let s = scrubber.clone();
        on(hit, lv_event_code_t_LV_EVENT_PRESSING, move |_| {
            if let Some((x, y)) = point() {
                s.drag(x, y);
            }
        });
        let s = scrubber.clone();
        on(hit, lv_event_code_t_LV_EVENT_RELEASED, move |_| s.release());
        let s = scrubber.clone();
        on(hit, lv_event_code_t_LV_EVENT_PRESS_LOST, move |_| s.lost());
        scrubber
    }

    /// Show playback: the ring, knob and caption follow `position_ms` unless
    /// a finger is dragging; ticks are rebuilt only when the marks change.
    pub fn set(&self, position_ms: u32, duration_ms: u32, marks_ms: &[u32], playing: bool, playable: bool) {
        let mut inner = self.inner.borrow_mut();
        let next = Shown {
            position_ms,
            duration_ms,
            marks_ms: marks_ms.to_vec(),
            playing,
            playable,
        };
        if inner.shown.as_ref() == Some(&next) {
            return;
        }
        let ticks_changed = inner.shown.as_ref().is_none_or(|shown| {
            shown.duration_ms != duration_ms
                || shown.marks_ms != marks_ms
                || shown.playable != playable
        });
        inner.icon
            .hidden(!playable)
            .set_text(if playing { icons::PAUSE } else { icons::PLAY });
        inner.shown = Some(next);
        if ticks_changed {
            inner.rebuild_ticks();
        }
        if !matches!(inner.gesture, Gesture::Scrub { .. }) {
            inner.draw_at(fraction(position_ms, duration_ms));
        }
    }

    pub fn press(&self, x: i32, y: i32) {
        let mut inner = self.inner.borrow_mut();
        if !inner.playable() {
            inner.gesture = Gesture::Idle;
            return;
        }
        inner.gesture = match zone(x, y) {
            Zone::Centre => Gesture::Centre,
            Zone::Ring => {
                let at = angle_at(x, y) / 360.0;
                inner.draw_at(at);
                Gesture::Scrub { x, y, at, moved: false }
            }
            Zone::Outside => Gesture::Idle,
        };
    }

    pub fn drag(&self, x: i32, y: i32) {
        let mut inner = self.inner.borrow_mut();
        match inner.gesture {
            Gesture::Centre if zone(x, y) != Zone::Centre => inner.gesture = Gesture::Idle,
            Gesture::Scrub { x: x0, y: y0, at, moved } => {
                let moved = moved || ((x - x0) as f32).hypot((y - y0) as f32) > DRAG_SLOP;
                let next = if moved { follow(at, angle_at(x, y)) } else { at };
                inner.draw_at(next);
                inner.gesture = Gesture::Scrub { x: x0, y: y0, at: next, moved };
            }
            _ => {}
        }
    }

    /// The finger lifted: the middle toggles playback; the ring seeks, to the
    /// nearest mark when it was a tap near a tick.
    pub fn release(&self) {
        let event = {
            let mut inner = self.inner.borrow_mut();
            match std::mem::replace(&mut inner.gesture, Gesture::Idle) {
                Gesture::Idle => None,
                Gesture::Centre => Some(ScrubEvent::TogglePlay),
                Gesture::Scrub { at, moved, .. } => {
                    let duration = inner.duration();
                    let snapped = if moved {
                        None
                    } else {
                        let marks = inner.shown.as_ref().map(|s| s.marks_ms.clone()).unwrap_or_default();
                        nearest_mark(at * 360.0, &marks, duration)
                    };
                    let ms = snapped.unwrap_or_else(|| to_ms(at, duration));
                    if let Some(shown) = inner.shown.as_mut() {
                        shown.position_ms = ms;
                    }
                    inner.draw_at(fraction(ms, duration));
                    Some(ScrubEvent::Seek(ms))
                }
            }
        };
        if let Some(event) = event {
            (self.on_event.borrow_mut())(event);
        }
    }

    /// LVGL lost the press: a scrub commits where it is, a centre press is dropped.
    pub fn lost(&self) {
        let centre = matches!(self.inner.borrow().gesture, Gesture::Centre);
        if centre {
            self.inner.borrow_mut().gesture = Gesture::Idle;
        } else {
            self.release();
        }
    }

    pub fn hit(&self) -> Obj {
        self.inner.borrow().hit
    }

    pub fn knob(&self) -> Obj {
        self.inner.borrow().knob
    }

    pub fn icon(&self) -> Obj {
        self.inner.borrow().icon
    }

    pub fn time(&self) -> Obj {
        self.inner.borrow().time
    }

    pub fn tick_count(&self) -> usize {
        self.inner.borrow().ticks.len()
    }
}

impl Inner {
    fn playable(&self) -> bool {
        self.shown.as_ref().is_some_and(|s| s.playable)
    }

    fn duration(&self) -> u32 {
        self.shown.as_ref().map_or(0, |s| s.duration_ms)
    }

    /// Progress, knob and caption at `at` (0..1 of the file).
    fn draw_at(&self, at: f32) {
        let at = at.clamp(0.0, 1.0);
        let duration = self.duration();
        let playable = self.playable();
        // SAFETY: live arc (range 0..1000 from `full_ring`).
        unsafe { lv_arc_set_value(self.ring.raw(), (at * 1000.0).round() as i32) };
        let (x, y) = polar(CX, CY, R as f32, at * 360.0);
        self.knob.pos(x - KNOB / 2, y - KNOB / 2).hidden(!playable);
        self.time
            .hidden(!playable)
            .set_text(&time_text(to_ms(at, duration), duration));
    }

    /// One 3° tick on r 70 per mark, square-ended, in Text 2.
    fn rebuild_ticks(&mut self) {
        for tick in self.ticks.drain(..) {
            tick.delete();
        }
        let duration = self.duration();
        if !self.playable() || duration == 0 {
            return;
        }
        let marks = self.shown.as_ref().map(|s| s.marks_ms.clone()).unwrap_or_default();
        for mark in marks {
            let deg = fraction(mark, duration) * 360.0;
            let tick = arc(self.layer, CX, CY, TICK_R, TICK_WIDTH);
            // SAFETY: live arc.
            unsafe {
                lv_arc_set_bg_angles(
                    tick.raw(),
                    lvgl_angle(deg - TICK_SPAN / 2.0),
                    lvgl_angle(deg + TICK_SPAN / 2.0),
                );
            }
            arc_style(tick, MAIN, TEXT_2, 255, TICK_WIDTH);
            arc_style(tick, INDICATOR, TEXT_2, 0, TICK_WIDTH);
            // SAFETY: live arc; the mockup's ticks have butt ends.
            unsafe { lv_obj_set_style_arc_rounded(tick.raw(), false, MAIN) };
            self.ticks.push(tick);
        }
    }
}

//! Recording detail (docs/mockups file-detail.png): the dial becomes a
//! playback scrubber, Delete sits on the left, Send / Send again on the
//! right, and the upload state or failure reason under them.

use super::files::{sentence, status_look};
use crate::kit::icons;
use crate::kit::snapshot::UiSnapshot;
use crate::kit::tokens::{TEXT_2, WARN};
use uuid::Uuid;
use waved_state::{PlaybackState, RecordingStatus, RecordingSummary};

/// After a seek, show its target until playback reports a position within
/// `SEEK_TOLERANCE_MS` of it, or for at most `SEEK_SETTLE_MS`.
pub const SEEK_SETTLE_MS: u64 = 1_500;
pub const SEEK_TOLERANCE_MS: u32 = 1_000;
pub const SENDING: &str = "Sending the recording";
pub const BUSY_RECORDING: &str = "Can't play while recording";
pub const BUSY_CALL: &str = "Can't play during a call";

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct PlayView {
    /// The speaker is playing (or paused on) this recording.
    pub active: bool,
    pub playing: bool,
    pub position_ms: u32,
    pub duration_ms: u32,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct PendingSeek {
    pub target_ms: u32,
    pub sent_at_ms: u64,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum CentreTap {
    Play { from_ms: u32 },
    Pause,
    Resume,
    Refuse(&'static str),
    Nothing,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum SendAction {
    Send,
    SendAgain,
}

impl SendAction {
    pub fn icon(self) -> &'static str {
        match self {
            SendAction::Send => icons::SEND,
            SendAction::SendAgain => icons::REFRESH,
        }
    }

    pub fn label(self) -> &'static str {
        match self {
            SendAction::Send => "Send",
            SendAction::SendAgain => "Send again",
        }
    }
}

/// What the scrubber shows for recording `id`. Playback of another recording
/// is ignored; until this one plays, the position is the locally chosen
/// start (`local_ms`) and the duration comes from the summary.
pub fn play_view(id: Uuid, rec: &RecordingSummary, playback: &PlaybackState, local_ms: u32) -> PlayView {
    let active = playback.recording == Some(id);
    let duration_ms = if active && playback.duration_ms > 0 {
        playback.duration_ms
    } else {
        rec.duration_secs.saturating_mul(1_000)
    };
    let position_ms = if active { playback.position_ms } else { local_ms }.min(duration_ms);
    PlayView {
        active,
        playing: active && playback.playing,
        position_ms,
        duration_ms,
    }
}

/// Marks from the playback when it is this recording's, else from the summary.
pub fn marks_for<'a>(id: Uuid, rec: &'a RecordingSummary, playback: &'a PlaybackState) -> &'a [u32] {
    if playback.recording == Some(id) && !playback.marks_ms.is_empty() {
        &playback.marks_ms
    } else {
        &rec.marks_ms
    }
}

pub fn shown_position(actual_ms: u32, pending: Option<PendingSeek>, now_ms: u64) -> (u32, Option<PendingSeek>) {
    match pending {
        Some(seek)
            if actual_ms.abs_diff(seek.target_ms) > SEEK_TOLERANCE_MS
                && now_ms.saturating_sub(seek.sent_at_ms) < SEEK_SETTLE_MS =>
        {
            (seek.target_ms, Some(seek))
        }
        _ => (actual_ms, None),
    }
}

pub fn playable(rec: &RecordingSummary) -> bool {
    rec.status != RecordingStatus::Damaged && rec.duration_secs > 0
}

/// Why playback can't start now: the speaker would play into a recording,
/// or over a call.
pub fn play_guard(snap: &UiSnapshot) -> Option<&'static str> {
    if snap.meeting.recording {
        Some(BUSY_RECORDING)
    } else if snap.in_call() {
        Some(BUSY_CALL)
    } else {
        None
    }
}

/// What a tap in the middle does. Pausing is always allowed.
pub fn centre_tap(view: &PlayView, local_ms: u32, playable: bool, guard: Option<&'static str>) -> CentreTap {
    if !playable {
        return CentreTap::Nothing;
    }
    if view.playing {
        return CentreTap::Pause;
    }
    if let Some(reason) = guard {
        return CentreTap::Refuse(reason);
    }
    if view.active {
        CentreTap::Resume
    } else {
        CentreTap::Play { from_ms: local_ms }
    }
}

/// "Send" for a recording kept on Wave, "Send again" after a failure; nothing
/// once it is sent or on its way, for damaged files, or without a server.
pub fn send_action(status: RecordingStatus, server_set: bool) -> Option<SendAction> {
    if !server_set {
        return None;
    }
    match status {
        RecordingStatus::LocalOnly => Some(SendAction::Send),
        RecordingStatus::Failed => Some(SendAction::SendAgain),
        _ => None,
    }
}

/// The line under the scrubber: the failure and its reason in amber, or the
/// upload state in Text 2.
pub fn note_line(rec: &RecordingSummary, wifi_connected: bool) -> (String, u32) {
    let (_, _, words) = status_look(rec.status, wifi_connected);
    let head = sentence(words);
    match rec.status {
        RecordingStatus::Failed | RecordingStatus::Damaged => {
            let reason = rec.last_error.as_deref().map(str::trim).filter(|r| !r.is_empty());
            let text = match reason {
                Some(reason) => format!("{head}: {reason}"),
                None => head,
            };
            (text, WARN)
        }
        _ => (head, TEXT_2),
    }
}

/// The note box: room for "Upload failed: server didn't answer", narrow
/// enough to stay inside the panel at y 218 (about 314 px visible there).
const NOTE_W: i32 = 300;

/// What the handlers need from the last snapshot.
#[derive(Default)]
struct Live {
    view: PlayView,
    playable: bool,
    guard: Option<&'static str>,
    /// The start chosen on the ring before this recording plays.
    local_ms: u32,
    pending: Option<PendingSeek>,
    now_ms: u64,
}

fn on_scrub(id: Uuid, live: &RefCell<Live>, dispatch: &Dispatcher, event: ScrubEvent) {
    let mut live = live.borrow_mut();
    match event {
        ScrubEvent::TogglePlay => match centre_tap(&live.view, live.local_ms, live.playable, live.guard) {
            CentreTap::Play { from_ms } => {
                dispatch.command(Command::PlayRecording(id));
                if from_ms > 0 {
                    dispatch.command(Command::SeekPlayback(from_ms));
                }
            }
            CentreTap::Pause => dispatch.command(Command::PausePlayback),
            CentreTap::Resume => dispatch.command(Command::ResumePlayback),
            CentreTap::Refuse(text) => dispatch.show(Severity::Info, text),
            CentreTap::Nothing => {}
        },
        ScrubEvent::Seek(ms) => {
            if live.view.active {
                dispatch.command(Command::SeekPlayback(ms));
                live.pending = Some(PendingSeek {
                    target_ms: ms,
                    sent_at_ms: live.now_ms,
                });
            } else {
                live.local_ms = ms;
            }
            live.view.position_ms = ms;
        }
    }
}

    /// Show, swap or remove the right-hand button. A changed action rebuilds
    /// it; deleting the circle deletes its label too.
    fn sync_send(&mut self, wanted: Option<SendAction>) {
        if self.send.as_ref().map(|(action, _)| *action) == wanted {
            return;
        }
        if let Some((_, button)) = self.send.take() {
            button.obj().delete();
        }
        let (Some(action), Some(root), Some(dispatch)) = (wanted, self.root, self.dispatch.clone()) else {
            return;
        };
        let id = self.id;
        let button = RoundButton::at(
            root,
            DETAIL_SIDE_RIGHT,
            DETAIL_SIDE_RIGHT_LABEL,
            action.icon(),
            action.label(),
            Tone::LiveIcon,
            move || {
                dispatch.command(Command::RetryUpload(id));
                dispatch.show(Severity::Info, SENDING);
            },
        );
        self.send = Some((action, button));
    }
}

impl Screen for FileDetailScreen {
    fn build(&mut self, root: Obj, ctx: &ScreenCtx, snap: &UiSnapshot) {
        self.root = Some(root);
        self.dispatch = Some(ctx.dispatch.clone());
        // Only the setup page changes the endpoint, and saving there restarts
        // waved (RestartForConfig), so the boot-time copy is current.
        self.server_set = !ctx.config.api.endpoint.trim().is_empty();
        self.status = Some(StatusArea::plain(root));
        self.title = Some(
            Obj::label(root, "", Font::Title, TEXT)
                .centered_text(SCREEN_W)
                .pos(0, TITLE_Y),
        );
        let (id, live, dispatch) = (self.id, self.live.clone(), ctx.dispatch.clone());
        self.scrubber = Some(Scrubber::new(root, move |event| {
            on_scrub(id, &live, &dispatch, event)
        }));
        let dispatch = ctx.dispatch.clone();
        self.delete = Some(RoundButton::at(
            root,
            DETAIL_SIDE_LEFT,
            DETAIL_SIDE_LEFT_LABEL,
            icons::TRASH,
            "Delete",
            Tone::Rec,
            move || dispatch.navigate(Route::Confirm(ConfirmKind::DeleteRecording(id))),
        ));
        self.note = Some(
            Obj::label(root, "", Font::Small, TEXT_2)
                .centered_text(NOTE_W)
                .pos((SCREEN_W - NOTE_W) / 2, DETAIL_NOTE_Y),
        );
        let back = back_button(root, &ctx.dispatch);
        let (live, dispatch) = (self.live.clone(), ctx.dispatch.clone());
        on_click(back, move || {
            if live.borrow().view.active {
                dispatch.command(Command::StopPlayback);
            }
        });
        self.back = Some(back);
        self.update(snap);
    }

    fn update(&mut self, snap: &UiSnapshot) {
        if let Some(status) = self.status.as_mut() {
            status.update(snap);
        }
        let Some(rec) = snap.files.recordings.iter().find(|rec| rec.id == self.id) else {
            // Deleted here or pruned by retention: back to Files, once.
            if !self.left {
                self.left = true;
                if let Some(dispatch) = &self.dispatch {
                    dispatch.back();
                }
            }
            return;
        };
        let title = when_label(
            rec.started_at.as_deref(),
            snap.now_unix_s,
            snap.utc_offset_min,
            snap.settings.clock_24h,
        );
        if let (Some(label), true) = (self.title, title != self.shown_title) {
            label.set_text(&title);
            self.shown_title = title;
        }
        let note = note_line(rec, snap.wifi.connected);
        if let (Some(label), true) = (self.note, self.shown_note.as_ref() != Some(&note)) {
            label.text_color(note.1).set_text(&note.0);
            self.shown_note = Some(note);
        }
        self.sync_send(send_action(rec.status, self.server_set));
        let (view, can_play) = {
            let mut live = self.live.borrow_mut();
            live.now_ms = snap.now_ms;
            let mut view = play_view(self.id, rec, &snap.playback, live.local_ms);
            if view.active {
                let (shown, pending) = shown_position(view.position_ms, live.pending, snap.now_ms);
                view.position_ms = shown;
                live.pending = pending;
            } else {
                live.pending = None;
            }
            live.view = view;
            live.playable = playable(rec);
            live.guard = play_guard(snap);
            (view, live.playable)
        };
        if let Some(scrubber) = &self.scrubber {
            scrubber.set(
                view.position_ms,
                view.duration_ms,
                marks_for(self.id, rec, &snap.playback),
                view.playing,
                can_play,
            );
        }
    }
}
