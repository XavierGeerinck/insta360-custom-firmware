## Goal and approach

Run NVIDIA Frame-VAD Multilingual MarbleNet v2.0 with real trained parameters
through the Wave NPU, compare its speech probabilities against independent
CPU references, and measure the complete inference boundary. Deploy only a
disposable lab package; preserve the running Wave services and production
CPU noise-reduction decision.

The preferred route exports a fixed-shape FP16 convolutional graph with
batch normalization folded into preceding pointwise/dense convolutions.
CPU handles exact checkpoint-defined log-mel extraction, output transpose,
softmax and thresholding. The whole convolutional backbone and classifier
become one NBG, avoiding host transfers between layers. Original FP32
checkpoint inference remains the accuracy reference.

Two alternatives were considered: offloading one trained convolution while
the rest remains CPU, which provides a useful bounded fallback experiment
but does not establish full-model NPU residency; and beginning with the
larger recurrent denoisers, which adds unrelated operator/state work. The
complete MarbleNet graph is the target. Report any native blocker precisely
and retain the working CPU deployment rather than claiming NPU success.

## Fixed input, model and numerical contracts

The deterministic audio fixture is mono float32, 16,000 Hz, exactly 63,840
samples (3.99 seconds). Centered STFT yields exactly 400 valid feature frames;
this differs from an exact four-second clip, which yields 401 valid frames
and padding to 402. The neural input is `[1,80,400]`; stride two yields 200
valid output frames. Native memory uses `[T,1,C,1]`; the final two-channel
logits are returned in NCW order and mapped on CPU to `[1,200,2]`.

Preprocessing matches the checkpoint: preemphasis 0.97, serialized
nonperiodic Hann window of length 400, centered reflect STFT with FFT 512
and hop 160, magnitude then power, serialized 80-band mel filter bank,
natural log with additive `2^-24`, no normalization and no inference dither.
With all 400 frames valid, the source's convolution masks are identities.

The encoder has separable depthwise/pointwise convolutions, twelve BN stages
with epsilon `1e-3`, three projected residual additions and nine ReLUs. No
activation is inserted between a depthwise convolution and its pointwise
convolution. The decoder is one Linear `128→2`, represented as pointwise
Conv, with softmax on CPU. Dropout is inactive in evaluation.

FP32 reconstruction, BN folding and decoder conversion must agree with an
independent source-matched reference before FP16 conversion. Native FP16
constant weights retain their bits; native FP32 bias is an exact conversion
from the exported FP16 bias. Imported ONNX graphs admit only inline fixed
FP16 NCW Conv, equal-shape Add and Relu in the bounded MarbleNet graph family.
Reject dynamic dimensions, external/overridable constants, unknown domains,
opsets/attributes, broadcasting and extra outputs before device contact.

Before live work, freeze operator/tensor/constant/model/source/binary/input
and oracle hashes. Per-tensor FP16 qualification uses finite outputs and
`abs(error) <= 0.02 + 0.02*abs(reference)` for every element. Final native
speech probabilities must differ by at most 0.02 from the original FP32
model and decisions at threshold 0.5 must agree on at least 99% of the
frozen audio frames. Retain actual output bytes and error metrics; numerical
tolerance never substitutes expected bytes for measured bytes. Existing
PoC 17 controls retain their exact byte-equality requirement.

The model's receptive field is 291 feature frames, with symmetric
lookahead of 145 frames (1.45 seconds plus STFT context). The first deployment
is an offline fixed-window VAD test. Twenty-millisecond output spacing does
not establish twenty-millisecond causal streaming latency.

Use the existing offline toolchain and exact Wave stack:

- TIM-VX `702715d714277376d7ff466b7b72833ff57564c1`.
- Runtime SHA-256
  `c984e063e9ab4fe4d7e7ac85e783d88a330f1560268924ba4f449f5b258478dc`.
- Runtime provenance SHA-256
  `58601a21a3ac1ff0435833d5d30409a43332a892c77047428cb9a54d658efade`.
- Docker image
  `sha256:a45f1308adfe3fc3b90e329e72d5efe9d743e6cc77017254d28bbba1c689586a`.
- Offline builds, read-only source/SDK; inspected AArch64 ELF/dependencies.
- Compile deadlines 15 seconds native/20 seconds host; inference 8/12 seconds.
- VPMN v2 target `0x1000000e`; exact tensors, section integrity and all CRCs.

Four controls, each compiled once with one size query and one export:

1. 18A: real first pointwise Conv + folded BN + Relu, using actual CPU
   depthwise activations; proves multichannel trained coefficients/bias.
2. 18B: real first complete residual block; proves depthwise convolutions,
   two repeats, projection, addition and activation.
3. 18C: real dilated separable block; proves the rate-two kernel.
4. 18D: complete folded FP16 neural model, including stride-two first layer
   and the two-class classifier, as one graph.

Maximum: four compiler invocations/eight public export API calls; one
qualification inference per partial control and four frozen audio inferences
for the full model (seven qualification Runs total). A separate, reviewed
benchmark may make four warm-ups and 32 measured Runs of the qualified full
graph, for at most 43 native Runs overall. No retry of a control. Skip
dependent controls after clean compiler rejection; native fault, timeout,
ambiguous exit, numerical failure or health change stops remaining native
work. Do not fall back to incompatible CLC or edit driver/firmware state.

Source analysis establishes TIM-VX dilation arguments as rates: use `{2,1}`
for ONNX temporal dilation two, and `{1,1}` for normal convolution. The old
`{0,0}` was an undilated alias; do not subtract one at the public TIM-VX API.
Depthwise uses multiplier one and native weights `[K,1,C,1]`; dense weights
use `[K,1,I,O]`. ONNX `[O,I,K]` payload order already has temporal index
fastest. Explicit symmetric temporal pads map to `{left,right,0,0}`.

Prime device output after Compile, guard host readback, atomically save
actual outputs and keep the alarm armed through graph/context teardown.
Bind package/model/lowering/ELF/NBG/input/actual-output/oracle evidence.
Numerical checks precede eligibility, while cleanup checks only the proven
owned inventory and healthy lifecycle. Revalidate system hashes, boot,
service identities, holders, NPU settings and diagnostic continuity before
deleting staging. All device actions remain controller-owned and sequential.
